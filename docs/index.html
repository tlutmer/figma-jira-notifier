Everything you need

Set it up once, let it run every morning.

🔍

Figma diff engine

Compares full node trees between runs — tracks added, removed, and updated layers by page and frame.

📋

Structured Jira comments

Posts rich ADF comments with page headings, sweeping-change grouping, and per-screen breakdowns.

⚡

Sweeping change detection

When the same change hits 3+ nodes, it's grouped at the top as a sweeping change instead of repeated per screen.

🖥️

Local browser GUI

Manage projects, credentials, and schedule in a clean web UI at localhost:3000. No CLI required.

📦

Single binary

Build a self-contained executable for macOS, Windows, or Linux. No Node.js or npm needed to run it.

👥

@mention team members

Configure Jira account IDs per project to @mention your frontend developers in every changelog comment.

Get started

Download the binary for your platform or run from source.

1

Download or clone

Grab a pre-built binary from the Releases page, or run from source:

git clone https://github.com/tlutmer/figma-jira-notifier.git
cd figma-jira-notifier
npm install
2

Start the server

From source: npm start  ·  Binary: run the executable for your platform.

npm start
# → 🚀 Figma → Jira Notifier running at http://localhost:3000
3

Configure in the GUI

Open localhost:3000, add your Figma token and Jira credentials in Global Settings, then add a project with a Figma URL and Jira ticket URL.

4

Run Now or wait for the schedule

Click ▶ Run Now for the first run (saves a baseline snapshot). The next run will post the diff to Jira.
